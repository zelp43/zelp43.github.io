Inside the tool

Nine modules, one window.

Everything that used to take five apps and an afternoon. Point Selecta Tool at your library and work.

Build Crates

Turn folders, playlists, files or whole drives into a streaming live crate, then sync them into Serato.

Live Library

Browse the library remote-built from preview, build and rename crates, replace or drop tracks, swap snapshots.

Duplicate Finder

Group every copy of the same song, find the dupes, and let every crate in your library point to one file.

Pro

Export & Backup

Export crates as a set folder with a tracklist, or archive your whole library into a restorable backup.

Pro

File Doctor

Find every broken file in your library and reconnect it, one at a time or hundreds in a single batch.

Pro

Tag Editor

Edit tags and filenames, bulk-fix artist and title, scan for BPM and key, and set cover art in place.

Pro

Sampler

Trigger samples from the sample bank, load them onto a controller, and keyboard or mouse across banks.

Pro

Cue Studio

Place, rename and colour cue points on the waveform, or import the ones you already set.
