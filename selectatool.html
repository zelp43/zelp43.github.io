FAQ Frequently Asked Questions
▼
What is Selecta Tool?+

Selecta Tool is a DJ library management app built for Serato DJ Pro. It lets you build and export crates, scan folders, find duplicates, preview tracks, and much more — all outside of Serato. Available for Mac (Intel & Apple Silicon) and Windows 10/11.

What's the difference between Basic and Pro?+

Basic covers the core workflow — crate building, scanning, duplicate finding, track preview, and exporting. Pro adds power-user features: Library Backup & Restore, File Doctor, Tag Editor, Library Snapshots, Cue Studio, the Sampler, and more. Both tiers ship under the same installer.

Is it a subscription or a one-time purchase?+

One-time purchase. Pay once, own it forever. No recurring fees, no expiry.

How do I receive my license key after purchasing?+

Your license key is delivered instantly via Gumroad to your email after checkout. Check your spam folder if it doesn't arrive within a few minutes. For direct purchases, the key is sent manually — usually within the same day.

Can I upgrade from Basic to Pro later?+

Yes. Purchase Pro at any time and enter your Pro license key in the app's Settings — no reinstall needed. Your existing crates and library data stay intact.

Does it work with Serato DJ Lite?+

Selecta Tool is built and tested for Serato DJ Pro. Serato DJ Lite uses the same library format so basic crate operations may work, but full compatibility is only guaranteed with Serato DJ Pro.

Will my Serato library be affected if something goes wrong?+

Selecta Tool writes to the standard Serato database format. We recommend using the Library Backup feature (Pro) before making large changes. Basic users can export a tracklist TXT before any major operation as a reference.
